# JTT_ballの概要
graph.pngがJTTのボールの木です. graph.txtから生成されていて, これを編集してすればgraph.pngの木が更新されます.
make_graph.pyは気にしなくていいです. AIが書いたので自分も中身がわかりません.

# graph.txtの仕様
a:b c  
のように書くと頂点aから頂点b,cにそれぞれ矢印を伸ばします.  
スペースで頂点を区切っているので頂点の名前にスペースを使用せず, "_"を使用してください.  
  
例えば頂点a,bから頂点cに矢印を伸ばすときは  
a:c  
b:c  
のように書くとできます.

# gitの使い方
(自分も初めて使うので最低限の知識しかありません)  
graph.txtを開いて右上の"Edit this file"を選択すると編集できます.  
編集が完了したら右上の"Commit changes"を選択し, メモ欄のところに変更点を軽く書いてください.  
"Commit changes"のボタンを押すと保存できます.
